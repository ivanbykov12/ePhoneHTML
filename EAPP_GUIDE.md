# 📱 ePhone Simulator - Система плагинов .eapp

## ✅ Что добавлено:

### 1. Папка Custom Apps
На рабочем столе появилась папка **Custom Apps** с иконкой 📁. В ней отображаются все загруженные пользовательские приложения.

### 2. Формат .eapp
Файлы `.eapp` - это JSON файлы с метаданными и кодом приложения.

### 3. Три способа добавить приложение:

#### Способ 1: Положить файл в папку
1. Создай файл `моё_приложение.eapp` в папке `public/apps/`
2. Добавь имя файла в `public/apps/manifest.json`
3. Перезагрузи страницу

#### Способ 2: Загрузить через UI
1. Открой папку **Custom Apps** на рабочем столе
2. Нажми кнопку ↑ (загрузка)
3. Выбери .eapp файл
4. Приложение появится в списке

#### Способ 3: Для ИИ
Передай ИИ файл `public/apps/PROMPT_FOR_AI.md` - это промпт с инструкциями как создавать .eapp приложения.

### 4. Примеры приложений:
- `template.eapp` - шаблон с базовой структурой
- `catch_star.eapp` - игра "Поймай Звезду"
- `reaction_test.eapp` - тест скорости реакции

### 5. API для приложений:
```javascript
ePhone.getScreenSize()     // размер экрана
ePhone.vibrate(pattern)    // вибрация
ePhone.save(key, value)    // сохранить данные
ePhone.load(key)           // загрузить данные
ePhone.closeApp()          // закрыть приложение
ePhone.getSettings()       // получить настройки
```

### 6. Управление приложениями:
- **Скачать** .eapp файл (кнопка ↓)
- **Удалить** приложение (кнопка 🗑)
- **Загрузить** новый файл (кнопка ↑)

## 📝 Структура .eapp файла:

```json
{
  "id": "my_app",
  "name": "Моё Приложение",
  "icon": "🎮",
  "color": "from-purple-500 to-pink-500",
  "version": "1.0.0",
  "author": "Ваше Имя",
  "description": "Описание",
  "code": "<div>HTML</div><style>CSS</style><script>JS</script>"
}
```

## 🎨 Доступные градиенты:
- `from-red-500 to-pink-500`
- `from-blue-500 to-purple-500`
- `from-green-500 to-teal-500`
- `from-yellow-500 to-orange-500`
- `from-purple-500 to-pink-500`
- `from-cyan-500 to-blue-500`
- `from-indigo-500 to-purple-500`

## 🚀 Как добавить своё приложение:

1. Создай файл `my_game.eapp` в `public/apps/`
2. Напиши JSON с кодом (смотри template.eapp)
3. Добавь `"my_game.eapp"` в `manifest.json`
4. Перезагрузи страницу
5. Приложение появится в Custom Apps!

## 💡 Советы:

- Редактируй .eapp файлы в Notepad++ или VS Code
- Приложения сохраняются в localStorage (не пропадут при перезагрузке)
- Можно скачать приложение как .eapp файл и поделиться
- Код выполняется в изолированном iframe
- Используй Tailwind CSS классы или обычный CSS

## ⚠️ Ограничения:

- Нет доступа к внешним API (CORS)
- Нет доступа к файловой системе
- Максимальный размер: ~1MB
- Код должен быть валидным HTML/CSS/JS
