# 📱 ePhone Simulator v3.5

Веб-симулятор смартфонов и планшетов (ePhone 8 / X / 14, ePad 10.1) с собственной экосистемой приложений **.eapp**. Стек: React + TypeScript + Vite + TailwindCSS.

## ✨ Что нового в версии 3.5

### 🔒 AOD (Always-On Display)
- Кнопка питания **⏻** справа от корпуса — выключает/включает экран
- На выключенном экране отображаются приглушённые часы (или полная темнота, если AOD отключён)
- Тап по AOD → экран блокировки → разблокировка свайпом вверх или нажатием
- В Настройках: включение/выключение AOD и **выпадающий список из 7 позиций часов** (углы, центр, низ)
- На iPhone 8 контент AOD, Пункта управления и eSiri обрезан по нижнюю рамку и не перекрывает кнопку Home

### 🧩 Виджеты на рабочем столе
- **Погода 2×2** (на ePad — 4×2) с реальной температурой и прогнозом
- **eSiri 1×4** — строка поиска, объединённая с ассистентом: введённый запрос уходит прямо в eSiri (живой поиск приложений + быстрые команды)
- Оптимизированная сетка под ePad (`auto-fill`, без растянутых элементов)

### 🤖 eSiri — голосовой помощник
- Вызов с рабочего стола, распознавание текстовых команд
- Запуск приложений, погода, быстрые действия

### 🔔 Уведомления в реальном времени
- Баннеры поверх экрана, Центр уведомлений, бейджи на иконках

### 👆 Жесты
- Свайпы между страницами рабочего стола
- Pinch-to-zoom сетки иконок
- Свайп для открытия Пункта управления (со статусбара) и разблокировки

### 🌤️ Реальная погода (Open-Meteo API)
- **Бесплатный API без ключа**
- 6 городов: Москва, СПб, Нью-Йорк, Лондон, Токио, Дубай
- Реальная температура, влажность, ветер, давление
- Почасовой прогноз на 12 часов и прогноз на 7 дней

### 🎮 Новые игры
- **eBreakout** — арканоид
- **Парочки** — memory game
- Итого игр в комплекте: 6 (Змейка, Тетрис, 2048, Flappy Bird, eBreakout, Парочки)

## 🎨 Дизайн (v3.0)

- **Glassmorphism** — размытие фона, полупрозрачные панели
- **Градиентные фоны** — уникальные у каждого приложения
- **Плавные анимации** — cubic-bezier easing на всех переходах, анимации переходов между приложениями
- **Тёмная тема по умолчанию**
- **Dynamic Island** — плавное расширение/сжатие, индикатор активности
- **Control Center** — на iPhone 8 открывается снизу, на X/14 сверху; вертикальные слайдеры яркости/громкости

## 📦 Приложения .eapp (19 системных)

**Игры:** Змейка · Тетрис · 2048 · Flappy Bird · eBreakout · Парочки
**Утилиты:** Калькулятор · Часы · Заметки · Настройки · Погода
**Медиа:** Фото · Музыка
**Сервисы:** Safari · Сообщения · Карты · Здоровье · App Store · Настройка (welcome)

Формат поддерживает версии **eApp v1.0 и v1.1**: кастомные стили, фоны, внешние библиотеки (CDN), разрешения, ориентация, полноэкранный режим.

### 🛡️ Защита от «шума»
При импорте .eapp и загрузке из localStorage проверяется поле `code`: сырой JSON-дамп вместо HTML-кода приложения отклоняется и на экран не попадает.

## 🚀 Как запустить

### Dev сервер
```bash
npm install
npm run dev
# Откройте http://localhost:5173
```

### Production build
```bash
npm run build
# Файлы в папке dist/
```
