# 📱 ePhone Simulator v3.0 - Полная переработка

## ✨ Что нового в версии 3.0

### 🎨 Полностью новый дизайн
- **Glassmorphism эффекты** - размытие фона, полупрозрачные элементы
- **Градиентные фоны** - все приложения имеют уникальные градиенты
- **Современные тени** - мягкие тени для глубины
- **Плавные анимации** - все переходы с cubic-bezier easing
- **Тёмная тема по умолчанию** - стильный тёмный интерфейс

### 🏝️ Dynamic Island (переосмысленный)
- Плавная анимация расширения/сжатия
- Градиентная иконка приложения
- Зелёный пульсирующий индикатор активности
- Красивые переходы между состояниями

### 🎛️ Control Center (шторка)
- **iPhone 8** - открывается снизу (slide-from-bottom)
- **iPhone X/14** - открывается сверху (slide-down)
- Glassmorphism фон с blur эффектом
- Круглые кнопки с анимациями
- Вертикальные слайдеры яркости/громкости
- Анимация закрытия

### 📱 Рамки и статусбар
- **iPhone 8** - верхняя рамка 80px, статусбар внутри рамки
- **iPhone X** - статусбар выше (50px)
- **iPhone 14** - стандартный (54px)
- Расстояние между иконками статусбара уже (px-6/px-7)
- Док-панель поднята выше (mb-24)

### 🌤️ Реальная погода (Open-Meteo API)
- **Бесплатный API без ключа**
- 6 городов: Москва, СПб, Нью-Йорк, Лондон, Токио, Дубай
- Реальная температура, влажность, ветер, давление
- Почасовой прогноз на 12 часов
- Прогноз на 7 дней
- Автоматическое определение погодных условий

```css
/* Плавные переходы */
transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)

  to { opacity: 1; transform: scale(1) }

/* Пульсация */

}
```

## 🎨 Ключевые дизайн-решения

### 1. Glassmorphism
Все карточки и панели используют эффект размытия фона:
```css
backdrop-filter: blur(20px)
background: rgba(255, 255, 255, 0.06)
border: 1px solid rgba(255, 255, 255, 0.1)
```

### 2. Градиенты
Каждое приложение имеет уникальный градиент:
- Игры: яркие, энергичные цвета
- Утилиты: нейтральные, спокойные тона
- Сервисы: брендовые цвета

### 3. Тени
Многослойные тени для глубины:
```css
box-shadow: 
  0 4px 15px rgba(0, 0, 0, 0.2),
  0 8px 32px rgba(0, 0, 0, 0.3)
```

### 4. Анимации
Все интерактивные элементы имеют плавные переходы:
- Кнопки: scale(0.9) при нажатии
- Карточки: fade-in при появлении
- Модальные окна: scale + fade

## 🚀 Как запустить

### Вариант 1: Открыть готовую версию
```bash
# Просто откройте файл в браузере
open dist/index.html
```

### Вариант 2: Dev сервер
```bash
npm install
npm run dev
# Откройте http://localhost:5173
```

### Вариант 3: Production build
```bash
npm run build
# Файлы в папке dist/
```
